# Hola, Español — сайт школы испанского языка

Сайт на Next.js для школы испанского языка: главная страница, «Обо мне»,
«Цены» и «Записаться» с формой заявки (без бэкенда — только интерфейс).

## Как запустить локально

```bash
npm install
npm run dev
```

Затем откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Структура проекта

- `app/` — страницы (главная, `/about`, `/pricing`, `/booking`) и общий layout
- `components/` — секции страниц (`components/sections`) и общие UI-элементы
  (`components/ui`), шапка и подвал сайта
- `lib/` — тексты и данные сайта (`site-data.ts`) и вспомогательные функции

## Что можно поменять

- Тексты, цены и контакты — в файле `lib/site-data.ts`
- Цвета — в файле `app/globals.css` (переменные `--primary`, `--accent` и т.д.)
